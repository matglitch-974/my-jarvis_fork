# Agent Sherlock

Agent d'hygiene numerique (nom provisoire). Veille fuites (pseudos, emails, mots de passe), alias, durcissement. Outils cibles : Sherlock/Maigret/Holehe/GHunt, HaveIBeenPwned (API mdp gratuite), SimpleLogin/addy.io. Bras arme de la routine 3h (M7.2). EN ATTENTE de son moteur.

Statut : squelette pret a recevoir son moteur (un bundle de config par agent - jamais de binaire modifie).
Brancher via : sidecar Claude Agent SDK (option agents / systemPrompt custom + outils + modele).
